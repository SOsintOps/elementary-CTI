v0.8.0 — 2026-08-08

  • La pipeline degli articoli è attiva: 12 fonti curate interrogate a ogni ciclo dello scheduler, con deduplica esatta e near-duplicate
  • Nuova pagina Articoli (/ai/articles) con ricerca, filtri per fonte e TLP, e filtro "Solo prioritari"
  • Priority Intelligence Requirements: la watchlist attiva definisce cosa conta, e gli articoli che la intercettano sono contrassegnati
  • Prima serie temporale dell'applicazione: vittime per mese sulla dashboard, con selettore di intervallo e sparkline per avversario
  • Matrice di copertura ATT&CK (/attack) e raggruppamento degli articoli per campagna (/ai/campaigns)
  • Export STIX 2.1 per avversario, pronto per MISP e OpenCTI
  • Alert triagati su tre livelli di severità, con flag "azionato" per misurare l'impatto sulle decisioni
  • Caching condizionale dei feed (etag / last-modified) e User-Agent con versione e contatto

v0.7.0 — 2026-06-12

  • Dark mode "noir" (tema della serie Elementary) con toggle ◐ e regolazione dimensione caratteri A−/A+
  • Design system sulla palette ufficiale elementary OS; Diamond Model e Pyramid of Pain ridisegnati (orientamento canonico)
  • Profili avversario multi-fonte: descrizione ransomware.live + profilo MITRE ATT&CK integrale, con storia delle versioni
  • Asset front-end completamente self-hosted (librerie e font Inter): nessuna richiesta remota
  • Tutte le segnalazioni della code review chiuse; schema: datetime timezone-aware, vincolo unico sui cyberattack, CASCADE sugli alert
  • Accessibilità: tab ARIA con navigazione da tastiera, focus visibile, contrasti corretti, alt sugli avatar

v0.6.0 — 2026-06-11

  • First tagged release: deployed as a Docker + PostgreSQL stack
  • Security hardening: XSS-safe feed URLs, optional HTTP Basic Auth, webhook SSRF guard, HTTP retries
  • Fixed ISO 8601 date parsing from ransomware.live (recent victims were saved without a date)
  • Concurrency-safe group ingest and MITRE enrichment timezone fix on PostgreSQL
  • Feed URL columns widened to TEXT (long onion URLs); SQLite→PostgreSQL migration tooling
  • v0.6 schema + AI foundation (Phase 1 of 7); AI analysis pipeline still in development

v0.4.0 — 2026-04-25

  • Rebrand: Pestilentia → Elementary CTI (Sherlock Holmes theme)
  • Light theme: white cards, gray background, blue accents inspired by elementary.io
  • Pixel art mugshot avatars (Pillow-generated, deterministic, height-scale backdrop)
  • Adversary search bar with live filtering on /groups page
  • Dashboard victims/adversaries panels with scrollbar overflow
  • Choropleth heatmap: land gray → deep red scale

v0.3.0 — 2026-04-24

  • MITRE ATT&CK enrichment: 971 TTPs across 46 groups via STIX 2.1 bundle (intrusion-set + software matching)
  • Adversary aliases imported from MITRE, displayed as tags on group detail pages
  • Country of origin flags on adversary cards, dashboard, and group detail pages
  • Dashboard victims card: 7-day / 1-month / 1-year time tabs with synchronized choropleth map

v0.2.0 — 2026-04-24

  • Full web interface: dashboard, victims, adversaries, cyberattacks, map, pipeline, search, guide
  • SOC-style dark palette with blue oceans, white borders, red-orange-yellow heat ramp
  • Choropleth maps on dashboard, full map page, and per-adversary detail pages
  • Adversary tools (776), MITRE ATT&CK TTPs (500), and references (96) imported and displayed
  • Dashboard "Most Active Adversaries" with 7-day / 1-month / 1-year tabs
  • "Refresh Now" button + last update timestamp on dashboard and adversary pages
  • Watchlist system: add target companies, automatic matching on ingest, alert notifications
  • Historical backfill: 27,122 victims, 360 groups, 3,434 cyberattacks, 185 countries
  • REST API: POST /api/v1/refresh endpoint for on-demand data updates
  • Database tracked in git (elementaryctiDB.db)
