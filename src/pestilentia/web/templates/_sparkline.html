{# Inline SVG sparkline — deliberately not Plotly. The adversary list renders every group at once (400+ cards), so a charting library instance per card is not an option. A sparkline has no axes, no legend and no hover by definition, so an SVG polyline is the whole shape. Renders nothing when the series is empty; a flat line at zero is a real signal ("dormant"), an absent series is not. #} {% macro sparkline(values, width=96, height=22, label="") %} {% if values and values | length > 1 %} {% set vmax = values | max %} {% set n = values | length %} {% set step = (width - 2) / (n - 1) %} {% endif %} {% endmacro %}
